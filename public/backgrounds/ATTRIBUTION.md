# Background asset attribution

All background assets in this directory were generated locally for Sakura Cactus. No external photographs, stock assets, remote URLs, or third-party trademarks are used.

| Asset | Source and author | License |
| --- | --- | --- |
| `paper-light.svg` | Procedurally generated SVG paper grain, created for Sakura Cactus by OpenAI Codex | MIT License (the Sakura Cactus project license) |
| `paper-dark.svg` | Procedurally generated near-black SVG paper grain, created for Sakura Cactus by OpenAI Codex | MIT License (the Sakura Cactus project license) |
| `window-shadow-light.webp` | Locally rendered from original geometric window and leaf-shadow shapes created for Sakura Cactus by OpenAI Codex | MIT License (the Sakura Cactus project license) |
| `window-shadow-dark.webp` | Locally rendered dark variant using original gray-green shadow shapes created for Sakura Cactus by OpenAI Codex | MIT License (the Sakura Cactus project license) |

The two WebP files contain transparent backgrounds and no embedded source metadata.
