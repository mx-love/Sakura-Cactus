# Security Checklist

This checklist will be expanded in stage 7.

- [ ] R2 bucket is private.
- [ ] R2 public development URL is disabled.
- [ ] R2 public custom domain is not configured.
- [ ] Secrets are not committed.
- [ ] Admin routes are protected.
- [ ] Admin APIs are protected.
- [ ] Session tokens are stored as hashes in D1.
- [ ] Markdown output is sanitized.
- [ ] Uploads are limited to safe image types.
